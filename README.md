# シフトノート

希望休のカレンダー画像を取り込み、週ごとにシフトを組むパソコン向けアプリです。

- 画像から希望休を判定し、確認してから反映
- 配置漏れ、時間の重複、希望休との重複、週の希望上限をチェック
- 勤務回数の集計、月間表の印刷、JSONバックアップ
- Googleログインで、ご本人専用のFirebase Realtime Databaseに保存
- 同時編集はバージョン確認で保護。競合時は未同期内容を退避してから最新版を開く

公開するのはプログラムと汎用の初期表示だけです。実際のスタッフ名、希望休、配置、バックアップ画像をリポジトリに追加しないでください。

GitHub Pagesではmainブランチのルートを配信します。ローカル成果物の`dist`内のファイルをリポジトリのルートに配置しています。

Firebaseのクライアント設定は認証秘密情報ではありません。データへのアクセスはFirebase Authenticationとデータベースのルールで制御します。認証済みアカウント自身の領域だけを許可し、所有者の承認済みアカウントに限定しています。別のアカウントはデータを読めません。

初回はGoogleでログインし、「読み込み」から既存バックアップを選択します。以後は同じGoogleアカウントでログインし、「クラウド保存済み」を確認して閉じてください。インターネットに接続できない場合、変更は端末に退避されます。ブラウザのデータを削除する前にバックアップを保存してください。

同時に複数の画面で変更すると競合することがあります。「この画面の変更をバックアップ」で退避し、「クラウドの最新版を開く」で続けます。バックアップの読み込みは全月・全設定の置き換えです。
